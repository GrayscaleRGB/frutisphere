# Roadmap

## v0.1 Explorer Prototype

1. Foundation: scaffold Vite/React/TypeScript, write project docs, add taxonomy
   records and validation, and keep a runnable baseline.
2. Explorer: build the Alba Aero environment, compact header, three complete
   placeholder tiles, desktop proximity emphasis, and mobile snap carousel.
3. Navigation: add equal-size Level 3 grids and reusable Level 4 pages with
   nested subcategories and graph relationships.
4. Appearance: add Quick Access themes, accents, sample special themes, Recent
   special-theme persistence, and reduced-motion support.
5. Discovery: add local name/alias search and polish keyboard/touch behavior.
6. Verification: test taxonomy rules, routes, persistence, responsive layouts,
   production build, and static-host behavior.

## After v0.1 review

- Replace placeholders only with approved complete tile artworks.
- Refine taxonomy and authored content with research and citations.
- Add historical-example and gallery metadata workflows.
- Consider a relationship map after the core atlas is stable.
- Evaluate community features as a separate, later product phase.

The roadmap intentionally excludes broad social infrastructure and expansion
into a general aesthetics encyclopedia.
